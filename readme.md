# From Raw to Ready: Data Preparation in Python

Short course about Data Loading and Manipulation

## What is covered

- Import data from various sources - Access and extract data from databases, APIs, flat files, and cloud storage using efficient and reliable methods for seamless data acquisition

- Transform data using Pandas and NumPy - Apply industry-standard Python libraries to reshape, clean, and enhance datasets through vectorized operations and sophisticated data manipulation techniques

- Handle different data types effectively - Develop strategies for managing text, categorical, numerical, and time-series data to ensure consistency and optimize analysis workflows

## Key Milestone

- Build a multi-source data integration pipeline - 

- Develop an end-to-end data pipeline that extracts, transforms, and integrates data from multiple sources while maintaining data integrity and documentation.

## Course Datasets

The course works with two datasets that simulate real-world data challenges. 

*The EngageMetrics* dataset represents a leading analytics company specializing in digital marketing optimization, while the *MediTrack* Health Solutions dataset represents a cutting-edge healthcare management company
